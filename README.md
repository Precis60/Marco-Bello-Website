## Public site URL

Canonical URLs, `sitemap.xml`, `robots.txt`, Open Graph and JSON-LD resolve
through `getSiteUrl()` in `src/lib/site.ts`. When a custom domain is added,
set `NEXT_PUBLIC_SITE_URL` in the Vercel project (Production and Preview) to
that origin, for example `https://bellomarco.com.au`. Leave preview and
branch hosts unset so those deployments keep the production origin. If the
variable is empty, production falls back to `VERCEL_PROJECT_PRODUCTION_URL`,
then `https://marco-bello-website.vercel.app`.
